ℹ️ Informasi Sistem

Sistem ini digunakan untuk memantau perubahan kondisi tanah melalui integrasi parameter statis dan dinamis. Parameter statis menggambarkan kondisi dasar lokasi, sedangkan parameter dinamis digunakan untuk memantau perubahan kondisi secara berkala.


Prototype menggunakan ESP32 sebagai mikrokontroler, sensor kelembapan tanah untuk parameter kadar air, MPU6050 untuk merepresentasikan perubahan kemiringan, dan potensiometer untuk merepresentasikan pergeseran horizontal.
